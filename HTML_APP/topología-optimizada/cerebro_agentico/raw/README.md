# raw/

Fuentes originales ya clasificadas: documentos, capturas, transcripciones,
datasets, exports, código de terceros. Material de referencia permanente.

- No se edita el contenido de estos archivos. Si hace falta corregir algo,
  se corrige en `wiki/`, citando la fuente.
- Organizar en subcarpetas temáticas a medida que surjan (ej.
  `raw/documentacion_api/`). No crear subcarpetas vacías por anticipado.
- Todo archivo acá debería poder rastrearse: de dónde salió y cuándo entró
  (una línea en `log/` al momento de archivarlo alcanza).

Ver `/AGENTS.md` para las reglas completas.
