# inbox/

Entrada cruda y temporal. Todo lo que se pega, sube o anota sin clasificar
todavía entra acá primero.

- No es un archivo definitivo: vida útil máxima, una sesión de trabajo.
- La IA debe procesar y vaciar esta carpeta regularmente, moviendo cada
  cosa a `raw/`, `wiki/`, `verdad/` o `proyectos/` según corresponda
  (ver `AGENTS.md` en la raíz).
- Formato libre: no hace falta prolijidad acá, es zona de aterrizaje.

Ver `/AGENTS.md` para las reglas completas.
