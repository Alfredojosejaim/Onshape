# wiki/

Conocimiento compilado y sintetizado. El producto elaborado, no la materia
prima (eso es `raw/`).

- Cada archivo debe responder "¿qué sabemos sobre X?" sin obligar a leer
  las fuentes originales.
- Es el primer lugar donde la IA debe buscar contexto antes de ponerse a
  trabajar sobre un tema.
- Un archivo por tema/concepto, nombrado con claridad
  (`wiki/convenciones-de-codigo.md`, `wiki/glosario-dominio.md`). Se crean
  a medida que hace falta, no de antemano.
- Cuando una nota de `wiki/` queda obsoleta, se actualiza o se marca como
  superada — no se borra sin dejar rastro si tiene valor histórico.

Ver `/AGENTS.md` para las reglas completas.
