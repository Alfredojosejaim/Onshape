# verdad/

Datos inmutables o de altísima confianza. La fuente de verdad del cerebro.

- Nada entra acá sin confirmación **explícita** del usuario en la
  conversación. Ante la duda, va a `wiki/`, no acá.
- Contenido típico: decisiones ya cerradas y no revisables, convenciones
  fijas, definiciones únicas de términos del dominio, restricciones de
  negocio o técnicas no negociables. Nunca secretos ni credenciales reales.
- Se edita muy raramente. Cualquier cambio acá debe quedar anotado en
  `log/` con la fecha y el motivo.

Ver `/AGENTS.md` para las reglas completas.
