# log/

Bitácora cronológica, append-only, de acciones relevantes sobre el cerebro.

- Un archivo por mes: `log/YYYY-MM.md`. Si no existe el del mes actual, se
  crea.
- Formato de línea:
  `YYYY-MM-DD HH:MM — [acción] — descripción breve — (proyecto, si aplica)`
- Se anota lo que valga la pena reconstruir después: movimientos entre
  capas, altas/bajas en `verdad/`, apertura o cierre de proyectos,
  decisiones importantes. No cada micro-paso.
- Nunca se edita o borra una entrada pasada: si algo cambió, se agrega una
  entrada nueva que lo aclare.

Ver `/AGENTS.md` para las reglas completas.
